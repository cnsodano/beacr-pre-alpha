# Read the debug log

Read the debug log

## Usage

``` r
read_logs(log_file = NULL)
```

## Arguments

- log_file:

  The custom log file path you wish to read. If no file is passed, a
  prompt menu will appear asking which log in the default log file
  directory you wish to read
