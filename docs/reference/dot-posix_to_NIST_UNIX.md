# Convert from R's POSIXct data type to the time encoding used by the NISTBeacon, namely **milliseconds** since epoch

Convert from R's POSIXct data type to the time encoding used by the
NISTBeacon, namely **milliseconds** since epoch

## Usage

``` r
.posix_to_NIST_UNIX(posix_time)
```
