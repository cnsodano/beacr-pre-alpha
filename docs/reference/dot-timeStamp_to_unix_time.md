# Converts a string return value from an API that represents a timestamp into a timestamp integer in the format expected by the NISTBeacon; namely, milliseconds since epoch

Converts a string return value from an API that represents a timestamp
into a timestamp integer in the format expected by the NISTBeacon;
namely, milliseconds since epoch

## Usage

``` r
.timeStamp_to_unix_time(timeStamp, round = FALSE)
```
